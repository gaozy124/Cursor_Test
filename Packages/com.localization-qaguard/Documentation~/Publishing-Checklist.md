# Publishing Checklist

Use this checklist before submitting to Unity Asset Store.

## Product

- [ ] Package imports cleanly in Unity 2021.3+
- [ ] Tool menu is discoverable and documented
- [ ] Core checks produce stable results on sample project
- [ ] Safe fix dry run and apply flows are verified
- [ ] CLI exit codes verified for fail-on modes

## Documentation

- [ ] README updated
- [ ] FAQ updated
- [ ] Changelog updated
- [ ] Quick start section added to listing page draft

## Media

- [ ] Icon prepared (256x256)
- [ ] Main screenshots (editor window, filtered issues, export output)
- [ ] 30–90s demo video (scan + export + safe fix dry run)

## Listing Content

- [ ] Clear value proposition in first paragraph
- [ ] Feature bullets map to concrete user outcomes
- [ ] Known limitations disclosed (dynamic key false positives)
- [ ] Support contact and response SLA included

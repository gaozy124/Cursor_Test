# Media Capture Guide (Asset Store)

Use this flow to record screenshots/video that map directly to product value.

## Screenshot Set

1. **Main UI Overview**
   - Open window with issue list visible
   - Show summary counts (errors/warnings/info)

2. **Rule Filtering**
   - Filter by severity + search term
   - Show focused issue triage flow

3. **Export**
   - Show JSON/CSV export action and output files

4. **Safe Fix Dry Run**
   - Enable dry run and show candidate/apply/skipped dialog

5. **Post-Fix Rescan**
   - Show reduced issue count after apply + rescan

## Demo Video Outline (45–90s)

1. Open tool and run scan
2. Review two issue classes (missing + placeholder mismatch)
3. Export report
4. Run safe fix in dry run
5. Apply safe fix and rescan
6. Mention CLI/CI gating in final frame

## Recording Notes

- Keep editor scale readable at 1080p.
- Avoid large cursor motions; highlight buttons deliberately.
- Use one compact sample project to keep recording short.
